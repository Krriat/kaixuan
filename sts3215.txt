STS3215 Driver ROS2 Package
STS3215 舵机 ROS2 驱动说明
=================================================


1. 项目介绍
=================================================

sts3215_driver 是一个基于 ROS2 的 STS3215 舵机控制驱动。

该驱动通过 USB-TTL 串口连接 STS3215-12V 舵机，
实现 ROS2 环境下对舵机的位置控制和当前位置读取。


当前实现功能：

√ 舵机位置控制

√ 舵机当前位置读取

√ ROS2 Topic通信

√ TTL串口通信

√ 单舵机控制


通信结构：

ROS2
 |
 |
sts3215_node
 |
 |
/dev/ttyACM0
 |
 |
USB-TTL
 |
 |
STS3215-12V
(ID=3)

3. 接线方式
=================================================


STS3215:

SIG
 |
 |---- USB-TTL TX/RX


GND
 |
 |---- USB-TTL GND


VCC

2. USB-TTL与舵机必须共地。

3. STS3215为单线半双工通信。

=================================================

8 bit

None

10. 位置控制
=================================================


控制Topic：


/sts3215/position



消息类型：


std_msgs/msg/Int32



发送的数据表示目标位置。


STS3215位置范围：


0 ~ 4095



-------------------------------------------------
示例1：移动到位置2048
-------------------------------------------------


ros2 topic pub \
/sts3215/position \
std_msgs/msg/Int32 \
"{data: 2048}"



-------------------------------------------------
示例2：移动到位置1000
-------------------------------------------------


ros2 topic pub \
/sts3215/position \
std_msgs/msg/Int32 \
"{data: 1000}"



-------------------------------------------------
示例3：移动到位置3000
-------------------------------------------------


ros2 topic pub \
/sts3215/position \
std_msgs/msg/Int32 \
"{data: 3000}"



=================================================
11. 当前位置读取
=================================================


读取Topic：


/sts3215/state



消息类型：


std_msgs/msg/Int32



查看当前位置：


ros2 topic echo /sts3215/state



输出示例：


data: 3015



表示：

当前舵机位置值为3015。



=================================================
12. STS3215通信协议
=================================================


协议格式：


FF FF ID LEN CMD DATA CHECKSUM



-------------------------------------------------
12.1 Ping测试
-------------------------------------------------


发送：


FF FF 03 02 01 F9



返回：


FF FF 03 02 00 FA



说明：

ID=3舵机通信正常。



-------------------------------------------------
12.2 读取当前位置
-------------------------------------------------


当前位置寄存器：

地址：

0x38


长度：

2 Byte



发送：


FF FF 03 04 02 38 02 BC



返回示例：


FF FF 03 04 00 C7 0B 26



解析：


位置低8位：

C7


位置高8位：

0B



计算：


position = 0x0B << 8 + 0xC7


结果：

3015



-------------------------------------------------
12.3 写入位置
-------------------------------------------------


写位置命令格式：


FF FF ID LEN CMD ADDRESS DATA CHECKSUM



驱动默认：

ID：

3


位置地址：

0x2A

13. 舵机方向调整
=================================================


由于机械安装方向不同，

位置增加方向可能与实际旋转方向相反。



例如：

软件：

1000 → 3000



实际：

顺时针 → 逆时针



可以修改代码：


原：

position = msg.data



改为：


position = 4095 - msg.data



实现方向反转。

14. 当前版本限制
=================================================


当前版本：


支持：

√ 单个STS3215舵机

√ ID固定为3

√ 固定串口/dev/ttyACM0

√ 位置控制

√ 当前位置读取



暂不支持：


× 多舵机控制

× 速度控制

× 扭矩控制

× 自动扫描ID

× ros2_control接口

# 七轴末端直线跟踪：中途推一下，比较偏离与恢复

用户选择的任务是：让末端走直线，多个关节同时运动，中途施加短暂外力。
本实验替换了原来的第七轴单独回零实验；旧配置、控制器、测试、说明与生成结果已删除。
七轴机器人、动力学基础和阶段 01 QP 保留。

## 当前默认的强扰动演示

用户反馈原视频距离短、扰动不明显，默认配置现为 `config/cartesian_lqr_demo.yaml`：
约 30 cm 的直线、5 N 峰值侧推、持续 1.5 s。完整仿真仍按真实比例回放，
视频新增中文阶段提示、实时力/误差曲线、等比例末端路径投影，并以 0.5 倍速播放。
具体观看顺序、配置与本机结果见 [强扰动演示](VISIBLE_DEMO.md)。
普通 PD 在强扰动下可能触发速度保护；该配置明确只要求 LQR 的常规运行完成，
对照的失败状态会保留，不能把提前停机的较小峰值误差当成胜出。

## 具体任务

所有数值写在 `config/cartesian_lqr.yaml`，不是从真机读取的姿态。

- 左臂七轴可动、右臂固定在零位、固定基座；无工具或额外负载。
- 初始关节角 `[0,-30,15,45,0,20,0]°`，区别于基础实验的全零初值。
- 静止 0.5 s，保持末端初始姿态，沿世界位移 `[0.06,0.04,0.02] m` 运动 3 s，再静止 1.5 s。
- 位移进度用 `s³(10−15s+6s²)`，起终点速度和加速度均为零。
- 每个 10 ms 参考点用上一点作逆运动学初值，构成连续的七轴关节曲线。
- 用关节三次样条取得 q/dq/ddq，并在每个 1 ms 点复核末端直线和姿态。
- 1 ms 物理步长、10 ms 控制周期；每个电机力矩在两次控制计算之间保持不变。

常规外力从 1.8 s 开始，持续 0.12 s，方向为世界 +Y，形状为 `0.5*sin²(pi*phase) N`。
峰值是 0.5 N，平均力是 0.25 N，冲量是 0.03 N·s。反向实验只改变外力符号。
压力测试乘以 4，峰值变为 2 N。它可能触发原有 90°/s 速度保护，不能将部分结果解释为完成恢复。

外力作用在**当前实际末端原点**，每个物理步重新计算 `tau_external = J(q)^T [F;0]`，
通过 MuJoCo `qfrc_applied` 施加，与电机力矩分开。单位测试另用 MuJoCo `mj_applyFT` 核对力臂和符号。
每步清空旧外力，避免脉冲结束后残留。
这是预先指定的外部力，不需要接触几何；它不代表已经建立碰撞/接触模型。

控制器只读取 q、dq、参考和模型，**不知道外力的时间、方向和大小**。
计算 LQR 时没有把这次推力作为已知未来输入；轨迹也没有为推力预先让路。

## 三种控制器到底有什么区别

动力学约定：

```text
M(q) * ddq + h(q,dq) = tau_motor + J(q)^T * wrench_external
h = c + G
```

参考前馈 `tau_ref = M(q_ref)*ddq_ref + h(q_ref,dq_ref)`，已经包含重力。
以下控制器全部返回总关节输出轴力矩 Nm，运行器不再次加 G。

1. **参考前馈加独立关节 PD**：`tau=tau_ref−Kp*e_q−Kd*e_dq`。
   Kp/Kd 为对角增益，用初始质量矩阵对角项和共同频率构造；反馈不显式协调轴间耦合。
2. **计算力矩加 PD**：`tau=M(q)*(ddq_ref−omega²*e_q−2*zeta*omega*e_dq)+h(q,dq)`。
   每次读取当前姿态的完整动力学，先补偿非线性耦合，再跟踪参考。这是较强的模型控制对照。
3. **时变 LQR**：`tau=tau_ref−K(t)*[e_q;e_dq]`。
   沿整条参考轨迹计算七轴耦合模型和反馈增益，在线只查表并做矩阵乘法。

默认两种 PD 的共同频率均为 12 rad/s、阻尼比为 1，便于对照其组织方式。
另外完整扫描 `[8,12,20,30,40,60,80] rad/s`，对名义和推力场景都保存结果。
频率为 80 rad/s 的计算力矩 PD 另在反向推力、延迟和压力场景测试，主图用紫色点线画出。
该设置是扫描中较快的强对照，不表示其在真机上已经适用。
扫描只有共同频率和固定阻尼比，不等于对独立 PD 的每个轴分别做了充分优化。

这些都是 MuJoCo 里的控制算法；没有模拟厂商完整 CSP/FOC 内环，也没有证明优于厂商位置模式。

## LQR 的设计步骤

在每个参考时刻定义 `x=[q−q_ref;dq−dq_ref]`、`u=tau−tau_ref`。
对 `f(q,dq,tau)=[dq; M(q)^−1*(tau−h(q,dq))]` 求中心差分，得到完整的 A(14×14)、B(14×7)。
用矩阵指数对局部连续模型作零阶保持离散化，得到 Ad、Bd。
不是把七个独立单轴控制器拼在一起。

状态代价包含：

- 末端位置误差，经线性近似 `delta_p=J_linear*e_q` 写入 Q；尺度为 5 mm。
- 末端姿态误差，经角速度雅可比写入 Q；尺度为 0.05 rad。
- 关节姿态误差 0.15 rad、关节速度误差 0.6 rad/s，用于约束冗余方向。
- 反馈力矩按 `[4,4,2,2,0.8,0.8,0.8] Nm` 归一化，写入 R。

这些尺度是控制设计选择，不是辨识参数，也不是硬约束。Q/R 都乘以控制周期。
以终点静止模型的无限时域 DARE 解作为终端 P，从后向前递推 500 步 Riccati 方程。
每一步检查有限性、正定性和控制驻点残差，并检查终点稳定性。
有限时变系统的稳定性不通过“每一步冻结模型的极点都稳定”来宣称。

中心差分另用不同方向和尺度核验；单位测试还用独立的整段二次问题直接求解，
比较整段控制序列，避免只检查递推公式自身。

参考轨迹是连续逆动力学可实现的样条；物理仿真采用离散采样保持，两者有离散化误差。
这里没有为 LQR 单独修正该误差；无扰动实验同时测出三者的基础跟踪误差。
理想控制模型不包含延迟、滤波、限幅或这次推力。它是参考附近的局部无约束设计，
不能宣称在任意初值、任意扰动、非理想执行器上都最优或稳定。

## 如何公平读结果

每种方法使用相同初值、参考、物理模型、推力和保护限值。控制器模型与物理仿真是独立对象。
默认 18 个主场景包括 15 个常规运行，以及 3 个较大推力运行；另有 PD 扫描和快速 PD 复核。
小扰动基准的 PASS 要求三种方法的常规运行完成并满足阈值；强扰动演示仅要求配置声明的 LQR 常规运行完成。压力测试和高增益扫描允许明确记录保护停机。
PASS 不能解释为每个压力测试都成功，也不要求 LQR 赢过对照。

- **峰值位置误差**：一次最严重偏离；RMS：整个运行的平均偏离。
- **恢复时间**：从推力结束算起，此后直到运行结束一直处于 1 mm 内的最早时间。
  如果始终没有超出 1 mm，则记 0 s，含义是“一直在带内”，不是瞬时纠偏。
- **共同二次代价**：各方法按相同 Q(t)/R/P 计算实际采样误差与实际电机力矩偏差，含终端项。
  只有完成的运行才可比较完整代价。停机运行标记 `cost_is_truncated=true`。
- **力矩/速度与保护**：同时查看总电机力矩、限幅次数、最大速度、故障状态，不能只看位置误差。
- **计算耗时**：分开记录离线设计和在线计算；桌面 Python 耗时不是机器人实时性保证。

延迟组只改变物理执行器：2 个物理步延迟加 5 ms 一阶响应，所有方法的设计仍使用理想模型。
每次运行从已经建立静态重力支撑的执行器状态开始，延迟队列也填同一平衡力矩。
这明确排除了启动下落的干扰，不是实机启动/控制器无缝切换实现。

## 当前结果应该怎样理解

详见同目录 `VALIDATION.md`。尤其要同时看较快计算力矩 PD：
在理想模型下，提高它的频率能比当前 LQR 获得更小的这次推力误差；
因此不能根据默认较慢 PD 的曲线宣传 LQR 普遍更好。
LQR 的“最优”针对设定的局部线性、无约束问题，不是对这个未知有限时长外力和非线性系统的所有控制方法排名。

模型仍沿用 CAD 参数。第七轴 armature 是估计值，其他轴的转子惯量尚未辨识。
本实验未连接机器人，不包含实际摩擦、力矩刻度误差或碰撞。这些限制见 `MODEL_ASSUMPTIONS.md`。

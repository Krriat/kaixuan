# CST 第 1 轴首次实机整定（2026-11-09）

本文件保留 PID 基线历史。默认外环现为 TV-LQI，当前参数和结果见 [CST_LQR.md](CST_LQR.md)。

已保留第 1 轴软件外环的一组实测参数。局部定位改善；整臂动态路径精度仍未通过验收。
本轮没有改写厂家驱动器增益、制动器参数或 EEPROM。退出后七轴去使能、零目标力矩、静止、无驱动故障。

## 手册对应的控制层

参考工作区根目录的《KGU系列 V1.2使用说明(6).pdf》PDF 第 26–28、58 页。

| 参数 | 对象索引 | 作用 |
|---|---|---|
| Pn031 / Pn032 | 0x2031 / 0x2032 | 驱动器电流环 P / I |
| Pn033 / Pn034 | 0x2033 / 0x2034 | 驱动器速度环 P / I |
| Pn063 / Pn065 | 0x2063 / 0x2065 | 驱动器位置环比例增益细调 / 粗调 |
| Pn064 | 0x2064 | 位置前馈，不是积分增益 |

手册给出参数含义、范围和读写方式，没有给出本项目 CST 外部位置 PID 的数值整定表。
第 58 页建议保留出厂性能参数。本项目 CST 模式下，位置/速度误差由
`cst_cartesian_math.py` 在 Orin 端转换为力矩，因此本轮优先调整这一层。
Pn031/032 等内环参数仅做备份和回读，不能用位置跟踪残差直接判定电流环需要改动。

## 已保留的参数

位置、速度单位为 rad、rad/s，输出为名义关节端 N·m。

| 第 1 轴参数 | 整定前 | 保留值 |
|---|---:|---:|
| Kp | 80 | 200 |
| Kd | 20 | 32 |
| Ki | 16 | 16 |
| 积分力矩限幅 | 5 N·m | 7 N·m |

参数位于 `config/cst_cartesian_test.yaml`。其他六轴 PID、20 N·m 总限幅所覆盖的轴、
力矩变化率以及速度/位移/误差/超时条件均保持本轮开始前的设置。
回退原参数可将 Kp 数组第一个数恢复 80、Kd 第一个数恢复 20、积分限幅第一个数恢复 5。

先用 Kp=200、Kd=32、原积分限幅 5 验证 2° 小幅运动，再在准备姿态验证积分限幅 7。
第 1 轴模型惯量约 0.399 kg·m²；P、D 的组合提高了纠偏能力，并保留接近原值的
局部线性模型阻尼比。这是工程候选选择依据，不是转子惯量辨识或全姿态稳定性证明。

## 实测结果与边界

- 2° 小幅测试：目标 −14.091°，最终 −14.004°，误差 0.087°，无目标越界；
  峰值速度 3.81°/s。此试验的积分限幅仍为 5 N·m。
- 保留参数的整臂测试：第 1 轴准备姿态残差 0.209°，上移终点稳定后残差 0.057°，
  回程等待结束时残差 0.150°。
- 已实际执行上移段。编码器结合活动 URDF 的 FK 给出 Z 位移 100.21 mm、
  终点误差 2.77 mm，但运动中最大横向偏差 19.72 mm、朝向偏差 4.59°，超出验收条件。
- 动态运动仍有明显关节误差：第 1 轴最大 2.08°，第 3 轴 2.23°，第 4 轴 6.80°。
  小幅定位结果不能代替动态精度验证。
- 回程在目标姿态等待 30 秒后，第 3 轴仍有 1.281° 残差，程序中止并去使能。
  没有完成后续返回最初姿态的阶段。

这些是编码器与 URDF 的估计，没有做独立末端测量或输出力矩标定。
还需分别处理反向运动、摩擦/模型误差以及第 3、4 轴动态跟踪，不能把当前参数称为整臂已调好。

## 调度与记录

一次普通调度的试验因 65.2 ms 控制循环停顿退出，50 ms 原保护保留。
整进程 FIFO/绑核试验在使能前因反馈陈旧退出，该运行方式已撤回。
最后一轮使用试验目录中的 `run_with_execution_priority.py`，仅在规划结束后将执行线程设为
CPU5 / FIFO20，DDS 通讯线程保持原调度。该辅助脚本没有改动默认控制入口。
最后一轮最大已记录循环间隔约 29 ms；Python 外环仍不能宣称具有硬实时确定性。

- `probe_200/experiment/`：2° 局部试验。
- `full_200_i7/experiment/`：已执行上移段的整臂试验及最终停稳记录。
